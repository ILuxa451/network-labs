# Network Labs

Практические лабораторные работы по сетям, маршрутизации и сетевой инфраструктуре. 
Стек: Linux (Ubuntu/Debian), Cisco Packet Tracer, VirtualBox.

## Цель
Систематизировать практические навыки по настройке сетей и документировать решения реальных задач (диагностика, маршрутизация, VLAN, VPN).

## Использование
Репозиторий носит учебный характер. Все конфиги обезличены, реальные IP-адреса заменены на тестовые.

## Лабораторные

### [Lab 01 — Соединение двух хостов (Point-to-Point)](./lab-01/)

*   Настройка статических IP-адресов для связи двух узлов.
*   Использование маски `/30` для изоляции сети из двух хостов.
*   Проверка связности через `ping`.

### [Lab 02 — Подсеть /28 (3 хоста + коммутатор)](./lab-02/)

*   Настройка трех хостов в одной подсети с маской `/28`.
*   Понимание ограничений подсети (16 адресов: 14 для хостов, 1 сеть, 1 broadcast).
*   Проверка связности между `host_3` и `host_1` через `ping`.

### [Lab 03 — Маршрутизация между подсетями](./lab-03/)

*   Настройка двух хостов в разных подсетях `/30`.
*   Настройка маршрутизатора с двумя интерфейсами.
*   Указание шлюзов по умолчанию для хостов.
*   Проверка связности через `ping` с прохождением через роутер.

### [Lab 04 — NAT и маршрутизация с одинаковыми IP](./lab-04/)

*   Настройка сети с двумя хостами, имеющими одинаковые IP-адреса (`10.0.0.5`).
*   Использование NAT (masquerade) на маршрутизаторах для устранения конфликта адресов.
*   Проверка связности с внешним сервером через `ping`.

### [Lab 05 — Статическая маршрутизация](./lab-05/)

*   Настройка сети из двух хостов и трех маршрутизаторов.
*   Добавление статических маршрутов на центральном маршрутизаторе (`router_3`).
*   Проверка связности между хостами в разных подсетях.

### [Lab 06 — Асимметричная маршрутизация](./lab-06/)

*   Настройка сети с двумя хостами и тремя маршрутизаторами.
*   Конфигурация разных путей для прямого и обратного трафика.
*   Проверка связности через `ping` с прохождением пакетов по разным маршрутам.

### [Lab 07 — Статическая маршрутизация и NAT](./lab-07/)

*   Настройка сети из 1 хоста, 3 маршрутизаторов и 2 серверов.
*   Конфигурация статических маршрутов на всех роутерах для обеспечения связности.
*   Настройка Source NAT (MASQUERADE) на `router_1` для решения проблемы обратной маршрутизации.
*   Проверка связности (`ping`) от `host_1` до `server_1` и `server_2` по разным путям.

### [Lab 08 — Маршрутизация с маской /32](./lab-08/)

*   Настройка двух хостов с точечной адресацией (`/32`).
*   Понимание работы шлюза по умолчанию при отсутствии широковещательного домена.
*   Использование IP-адресов друг друга в качестве шлюзов для прямого пинга.

### [Lab 09 — VLAN и Trunk-соединение](./lab-09/)

*   Настройка двух коммутаторов и 4 хостов.
*   Конфигурация Access-портов для разделения хостов в разные VLAN.
*   Настройка Trunk-порта между коммутаторами для передачи тегированного трафика (802.1Q).
*   Проверка изоляции широковещательного домена (host_1 пингует host_2, но не host_3/host_4).
